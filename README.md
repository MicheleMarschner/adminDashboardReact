# React Admin Dashboard

An admin dashboard built with React, featuring KPI cards, interactive charts, tables, and activity views.

## Features

- Dashboard components for displaying key metrics and activity data
- Interactive data visualizations using ApexCharts and ECharts
- Bootstrap-based UI components
- Serverless data integration using Netlify Functions

## Tech Stack

React 18 · JavaScript · Bootstrap 5 · ApexCharts · ECharts · Netlify Functions

## Getting Started

```bash
npm install
npm start
```

The application runs locally at `http://localhost:3000`.
